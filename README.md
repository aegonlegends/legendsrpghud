
Legends RPG HUD
=======

The development of this mod was started from a  desire to have an RPG-style HUD for Minecraft that was concise and not overtly text-based.

The intention is for the elements to not diverge too much from the Minecraft feel while providing all the battle and character info one would expect from RPG games.

The mod is still in development, and no release was created yet. Please look forward to it.
